# Praticando JS - Site com Animações

Projeto de estudo para praticar HTML, CSS e JavaScript, com foco em animações e interatividade na interface.

## Objetivo

Exercitar conceitos de JavaScript aplicados a uma interface visual, como:
- Manipulação do DOM
- Eventos de clique e interação do usuário
- Transições e animações em CSS

## Estrutura

- `index.html` — estrutura da página
- `style.css` — estilos e animações
- `scripts.js` — lógica e interatividade
- `img/` — imagens usadas no projeto

## Tecnologias

- HTML5
- CSS3
- JavaScript
